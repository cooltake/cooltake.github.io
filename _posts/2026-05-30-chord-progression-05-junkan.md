## 循環コードとは？音楽の「永久機関」

Cキーで：**C → Am → F → G（Ⅰ-Ⅵm-Ⅳ-Ⅴ）**

1950年代のアメリカのドゥーワップ（The Penguins「Earth Angel」など）で定着し、70年以上使われ続けている進行。英語では「'50s progression（フィフティーズ進行）」と呼ばれる。安定感・明るさ・推進力のバランスがよく、初心者でも弾きやすい。なお、ジャズなどでは Ⅰ-Ⅵm-Ⅱm-Ⅴ の進行を「循環コード」と呼ぶことも多い。この記事では Ⅰ-Ⅵm-Ⅳ-Ⅴ を扱う。

King）、Earth Angel、Blue Moon——50年代から定番の「50s Progression」</li><li><strong>日本</strong>：荒井由実「ルージュの伝言」（1975年）からAKB48「恋するフォーチュンクッキー」（2013年）まで、時代やジャンルを越えて使われている</li></ul></div>

## J-POPで循環コードが選ばれ続ける理由

循環コード（Ⅰ-Ⅵm-Ⅳ-Ⅴ）は50年代のドゥーワップで定着した進行だが、日本でも荒井由実「ルージュの伝言」（1975年）、ONE OK ROCK「C.h.a.o.s.m.y.t.h.」（2011年）、AKB48「恋するフォーチュンクッキー」（2013年）のように、時代やジャンルを越えて使われてきた。最後のⅤからⅠへ自然に戻れるので、4つのコードを何周くり返しても途切れずに続けられるのが強みだ。

<div style="background:#eceae7;border-radius:8px;padding:1.2rem 1.4rem;margin:1.5rem 0;border-left:4px solid #1e3a5f;"><h3 style="color:#111827;margin-top:0;font-size:1rem;font-weight:700;">🇯🇵 J-POPでの定着理由</h3><p style="color:#111827;margin:0;">Ⅰ→Ⅵm→Ⅳ→Ⅴという流れは、明るいⅠから始まり切ないⅥmを経由して再び明るさに戻る「感情の起伏」を作れる。このため、Aメロ・サビを問わずJ-POPのあらゆる場面で使われ続けている。似た響きを持つ<a href="/chord/chord-progression-01-oudo/" style="color:#1e3a5f;text-decoration:underline;">王道進行</a>と合わせて理解すると、J-POPのコード進行の全体像が掴みやすい。</p></div>

## ギターでの弾き方

C・Am・Gは開放弦を使うオープンコード。Fは人差し指で弦をまとめて押さえるセーハ（バレー）になるが、最初はFmaj7で代用してもよい。初心者が最初に覚えたい進行のひとつ：

```
C → Am → F → G
```

```
C  : ド・ミ・ソ
Am : ラ・ド・ミ
F  : ファ・ラ・ド
G  : ソ・シ・レ
```
