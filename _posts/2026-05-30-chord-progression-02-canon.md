## カノン進行とは？300年愛され続ける音楽の黄金律

ドイツの作曲家ヨハン・パッヘルベル（1653〜1706）の「カノン ニ長調」（作曲年ははっきりせず、1680〜1706年ごろとされる）。そのコード進行は300年以上たった現代のポップスにも受け継がれている。

**Cキーでのカノン進行：**
**C → G → Am → Em → F → C → F → G**

前半の6つのコードは、根音が「4度下がって2度上がる」動きをくり返す。転回形（コードの一番下の音を変える弾き方）を使うと、ベースは ド→シ→ラ→ソ→ファ→ミ と1音ずつ下がり、この落ち着いた下降が心地よさを生む。クラシックからパンク・ロック、J-POP、アニメの主題歌まで、ジャンルを越えて使われている。

C → G → Am → Em → F → C → F → G

## ピアノでの弾き方

```
左手ベース: ド→ソ→ラ→ミ→ファ→ド→ファ→ソ
```
